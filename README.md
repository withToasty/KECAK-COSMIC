# KECAK-COSMIC

**周期を重ねると、宇宙は音楽になる。**

KECAK-COSMIC は、ケチャのように複数の反復する声・リズムが重なってひとつの音楽になる構造を、宇宙に存在する「周期」へ拡張するプロジェクトです。

惑星の公転、自転、月の周期、人工衛星の軌道など、宇宙にはさまざまな反復があります。  
宇宙空間そのものに空気がなく音が伝わらなくても、**そこにある周期や関係性を音へ変換することはできる**。

このプロジェクトでは、次の2つを並行してつくります。

- **KECAK LOOP** — 円になって座る演奏者を操作し、複数の発声周期を重ねて演奏するWebルーパー
- **COSMIC MODE** — 天体・人工衛星などの実在する周期データを音楽へ変換する実験

## Core idea

> 宇宙の「音」を録るのではなく、宇宙の「時間」を聴く。

各天体や衛星をひとりの演奏者とみなし、それぞれ異なる周期で発声させる。  
単独では単純な反復でも、複数の周期が重なることで、長い時間をかけて変化するポリリズムが生まれる。

```
npm install

npm test           # pulse fixture + engine rules (vitest)
npm run build
```

`scripts/generate-placeholder-sounds.py`; replace them with recorded voices
