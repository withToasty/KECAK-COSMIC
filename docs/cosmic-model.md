# COSMIC MODE — 周期を音にする規則

Status: M2 first version

KECAK LOOP の「中心・軌道・周期・現在位置」という文法を、実在の天体と人工衛星の**周期**へつなぐ。
目的は宇宙っぽい BGM ではなく、**なぜその音がそのタイミングで鳴ったのかを、データで説明できること**
([concept.md](./concept.md) の原則 4)。変換規則はすべて純関数(`src/cosmos/compress.ts`)で、テストで固定している。

```
実際の周期(秒)
      ↓  ① 周期比を保つ 1 回の圧縮
拍で表した周期
      ↓  ② 軌道を 1 周するたびに 1 回鳴る(12時の位置を通る)
鳴る時刻(拍の中の小数の位置)
      ↓  ③ 周期の順位 → 音高
音(音高・種類・長さ)
```

## ① 圧縮: 比を保つ

最も周期の短い天体が 1 周する拍数 `fastestBeats`(既定 2〜4、1〜16 に変更可)を決め、
ほかは**実際の周期比をそのまま**掛けて拍数にする。丸めない。

```
periodBeats(b) = fastestBeats × realPeriod(b) / realPeriod(最速)
1拍 = realPeriod(最速) / fastestBeats   (全天体で共通の 1 つの値)
```

画面に「1拍 = 実際の 21.2 時間」のように出す。圧縮は 1 つの比だけで、天体ごとに倍率を変えない。

## ② 鳴る時刻: 拍の格子に載せない

1 周の始まりに鳴る。`periodBeats` が整数でなくても、鳴る時刻は `k × periodBeats`(拍)で厳密に計算し、
その拍の中の位置から audio 時刻へ直接変換する(12 subtick に丸めない)。Kecak の拍内ジェスチャーの格子とは別物。

- **最初は全員が同時に鳴る**(拍 0 で全天体が 1 周の始まり)。これは実際の天体の現在位置ではなく、
  「そろった状態から始めて、ずれていくのを聴く」ための決め事。
- 周期比が整数にならないので、ずれは消えない。次にそろう時刻は `nextRealignment` が計算して画面に出す。
- 別の天体が 0.08 拍以内に鳴ったら**合(conjunction)**として少し大きく鳴らし、中央も光らせる。

## ③ 音高: 周期の順位

周期の対数で順位を付ける。**周期が短いほど高く、長いほど低い**。音はハ長調のペンタトニック(3 オクターブ)に載せるので、
どの組み合わせでも濁らない。音色は種類で変える(惑星 = FM の鐘、衛星(月) = サイン波、人工衛星 = 三角波の短い音)。
どれも合成音で、サンプルを引き伸ばすことはしない。

## 系(listening system)

| 系 | 天体 | 最速の既定 |
|---|---|---|
| 地球まわり | ISS、GPS衛星、地球の自転、月 | 2 拍 |
| 内惑星 | 水星、金星、地球、火星 | 2 拍 |
| 外惑星 | 木星、土星、天王星、海王星 | 4 拍 |
| 木星の衛星 | イオ、エウロパ、ガニメデ、カリスト | 2 拍 |

最初は最速の 1 つだけが参加し、`JOIN NEXT BODY` か席のタップで周期の短い順に増やす(KECAK LOOP と同じ体験)。
参加・ミュート・テンポは次の拍の境界で反映される。圧縮(`fastestBeats`)は、全周期と位相が一度に変わるので停止中だけ変えられる。

**木星の衛星**は聴きどころ: イオ : エウロパ : ガニメデは実際にほぼ 1 : 2 : 4(精密には 1 : 2.007 : 4.045)の共鳴にあり、
カリストだけが外れている。そろうまでの時間がカリストの有無で変わることを、テストで確認している。

## データと確認状況

周期は恒星周期の平均値(秒)。静的な表で、**天体の現在位置は持たない**(実時間の追跡も外部 API もない)。

| 値 | 確認 |
|---|---|
| 水星 87.97 日、金星 224.70 日、火星 686.98 日、木星 4332.6 日、土星 10759 日 | 惑星の表の検索結果と一致を確認 |
| 月 27.32 日、イオ 1.769 日、エウロパ 3.551 日、ガニメデ 7.155 日、カリスト 16.69 日 | 検索結果と一致を確認(共鳴の比も同じ資料) |
| ISS 約 92.9 分、GPS 約 11 時間 58 分(恒星日の半分) | 検索結果と一致を確認。ISS は高度で変わる目安(`approx`) |
| 地球 365.256 日、天王星 30688.5 日、海王星 60182 日、地球の自転 86164.09 秒 | 一般に知られた値で、今回の検索では直接確認していない |

NASA の惑星ファクトシートなど一次に近い表へは、このセッションからは接続できなかったため直接照合していない。
一次の表で確認できれば、確認状況を更新する。

## やらないこと(M2 の範囲外)

- 実時間の追跡(今この瞬間の天体の位置、軌道要素、TLE)。
- 実際の軌道の形(楕円、傾き)の描画。円は「1 周」の意味だけを持つ。
- 周期以外のデータ(質量、距離、明るさ)の音への変換。
